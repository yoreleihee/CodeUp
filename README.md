# C++ 자료구조·알고리즘

C++ 문법과 자료구조·알고리즘을 학습하며 직접 작성한 코드를 모아둔 개인 학습 저장소입니다.

## 학습 방식

인터넷 검색과 AI를 사용하지 않고, 문제를 분석한 뒤 코드를 직접 설계하고 작성했습니다.
완성된 풀이를 따라 쓰기보다, 자료구조의 동작과 알고리즘의 흐름을 스스로 이해하며 구현하는 데 초점을 맞췄습니다.

## 저장소 구성

| 폴더 | 내용 |
| --- | --- |
| [C++ 기초](CodeUp/C%2B%2B_Fundamentals) | 입출력, 조건문·반복문, 배열, 함수, 포인터, 구조체·클래스, 상속, 템플릿, STL 연습 |
| [자료구조·알고리즘](CodeUp/Data_Structures_and_Algorithms) | 정렬, 재귀, 연결 리스트, 스택·큐, 해시, 그래프 탐색, 이진 탐색, 유니온 파인드, 힙, 동적 계획법 등 |
| [코딩 테스트 연습](CodeUp/CodingTest) | 배열, 문자열, 연결 리스트, 백트래킹 문제 풀이 |

## 주요 코드

- [정렬 알고리즘](CodeUp/Data_Structures_and_Algorithms/Sorting): 버블·선택·삽입·병합·퀵 정렬
- [그래프 관련 학습](CodeUp/Data_Structures_and_Algorithms/Graph): DFS·BFS, 트리, 유니온 파인드, 최소 신장 트리 등
- [동적 계획법](CodeUp/Data_Structures_and_Algorithms/DynamicProgramming)

각 폴더의 `.cpp` 파일에서 학습한 내용과 구현 코드를 확인할 수 있습니다.
학습 과정의 기록이므로 파일마다 작성 방식과 완성도는 다를 수 있습니다.
